# Windows10: сборка, прошивка и обновление R2

Зафиксированы ESP-IDF **5.5.1**, ESP32-S3, LVGL **9.6.0** и версия приложения
**2.0.0-r2**. IDF Component Manager загружает точную версию из manifest;
симулятор использует commit `80ca777e37a2b176770726a02e07a6fb79ef0b39`.
cJSON для JSON-профилей —1.7.19; прошивка использует библиотеку из IDF.

## Установка

Установите [официальный ESP-IDF Tools Installer](https://docs.espressif.com/projects/esp-idf/en/v5.5.1/esp32s3/get-started/windows-setup.html)
и выберите5.5.1. Откройте ESP-IDF PowerShell. Клонируйте репозиторий в каталог
без кириллицы/необычных символов; сохраните папки firmware,web,simulator иtools.

```powershell
git clone https://github.com/paradisemarketwb/bk-mikas-7.2.git
cd bk-mikas-7.2
cd firmware
idf.py set-target esp32s3
idf.py menuconfig
idf.py build 2>&1 | Tee-Object build-log.txt
```

В `BK Mikas R2`: Wi-Fi включён по умолчанию, физический K-Line выключен до
стендовой квалификации GPIO19/питания/UART. После неё включите BK_ENABLE_KLINE.
Целевые GPIO43/44 используются UART1, GPIO19 —TX_ARM, GPIO0 не используется.
Основная и вторичная консоли отключены, nativeUSB/SerialJTAG запрещены при такой
проводке. Нельзя включать USB-консоль только ради удобства отладки.

## Прошивка

Снять JP1 интерфейса K-Line. Выбрать на Waveshare USB-UART/CH343 по официальной
инструкции. Использовать защищённый сервисный пигтейл с развязкойVBUS,
как описано в [проводке](../WIRING.md). Прямой USB обходит ORing питания.
Узнайте COM-порт в диспетчере устройств и выполните:

```powershell
idf.py -p COM5 flash
```

COM5 заменяется реальным портом. Для диагностики поставить переключатель в
режим внешнегоUART, проверить TX/RX и только после стенда вернуть JP1.

Если передаются готовые binary вручную, использовать **все** адреса из
`firmware/build/flash_args` или `flasher_args.json`. В R2 есть otadata0xe000
и два app-раздела по3МиБ. Прошивка только app.bin на неправильный адрес не
является полной установкой; bootloader и partition-table должны соответствовать.
Flash16МиБ, PSRAM Octal80MHz — проверить точную ревизию дисплея.

## Что запускается

LCD/TCA9554/CST820 инициализируются до радио, чтобы сначала выделить internal
DMA/bounce/draw buffers. Дисплейный worker не владеет UART. Ошибка дисплея
оставляет подсветку выключенной и не создаёт цикл reset. При отсутствии ЭБУ
UI остаётся доступным; K-Line восстанавливает monitor0B автоматически.
600мс заставки реализованы LVGL timer без задержки диагностического worker.

NVS загружает профиль с проверкой версии/геометрии. Отсутствующий или повреждённый
профиль заменяется в RAM заводским; вся NVS автоматически не стирается.
Экран/яркость/тема/layout можно настраивать с телефона без перепрошивки.
[Телефон, импорт/экспорт и OTA](../getting-started/PHONE.md).

## Логи

`idf.py monitor` в обычной сборке не покажет сообщения приложения: консоли
выключены. Для изолированного стенда снятьJP1, отключитьBK_ENABLE_KLINE и
временно выбрать UART0console с переключателем наCH343; затем:

```powershell
idf.py -p COM5 flash monitor
```

Этот диагностический образ не использовать с подключённой K-Line ветвью.
Из логов перед отправкой удалить пароли, MAC, VIN и серийные данные.

## Восстановление

После неверного профиля используйте заводской сброс в телефоне или импорт
сохранённого JSON. После ошибки OTA действующий загрузочный раздел сохраняется,
K-Line остаётся заблокированной до ручного перезапуска. Если устройство не
загружается, снятьJP1 и восстановить через ROM/USB-UART полным набором binary.
Не включать nativeUSB вместо этого пути. Полное erase-flash уничтожает NVS
и пароль Wi-Fi; делать это только при осознанном восстановлении после экспорта.

## Сборка без реестра компонентов

Если именно реестр Espressif недоступен, взять официальную LVGL того же commit:

```powershell
git clone https://github.com/lvgl/lvgl.git C:\projects\lvgl
git -C C:\projects\lvgl checkout 80ca777e37a2b176770726a02e07a6fb79ef0b39
$env:IDF_COMPONENT_MANAGER="0"
idf.py "-DEXTRA_COMPONENT_DIRS=C:/projects/lvgl" build
```

На Linux: `IDF_COMPONENT_MANAGER=0 idf.py -DEXTRA_COMPONENT_DIRS=/path/to/lvgl build`.
Это способ воспроизвести сборку при недоступном сервере, не замена версии библиотеки.
Полные результаты проверок: [TESTING](../TESTING.md) и [статус R2](../R2_STATUS.md).
