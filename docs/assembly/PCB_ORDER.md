# Заказ платы и монтажа

Проект содержит две собственные платы: интерфейс BK-KLINE-R2 и защиту/питание
BK-POWER-R2. [Общий архив для изготовителя](../../hardware/fabrication/BK-R2-prototype-fabrication.zip)
содержит отдельные подпапки двух плат, BOM и позиции. Для каждой используйте
Gerber и Excellon из её KiCad-проекта:

- [Интерфейс: fabrication-prototype](../../hardware/kicad/r2/fabrication-prototype/).
- [Питание: проект и комплект экспорта](../../hardware/kicad/power-r2/README.md).

Gerber получены `kicad-cli` из настоящих `.kicad_pcb`, рисунок схемы не является
заменой производственных файлов. Перед загрузкой архивов в сервис проверьте
отображение меди, контура и сверловки в Gerber viewer изготовителя. Не смешивайте
слои двух разных плат или файлов из старого архива R1B.

Для ручного монтажа нужны медь двух слоёв, маски, шелкография, Edge.Cuts и drill.
Для автоматического монтажа дополнительно BOM с конкретными MPN и positions;
полярность/первый вывод следует сверять со схемой и datasheet. BOM не означает,
что поставщик сборки гарантированно имеет все компоненты на складе.

Базовый материал — FR4,1.6мм,2слоя,35мкм медь. Точные зазоры, отверстия,
допустимые токи, конструктив и статус каждого комплекта находятся в README
соответствующей платы и отчётах ERC/DRC. Токовые и высоковольтные цепи силовой
платы нельзя менять по умолчаниям дешёвого сервиса без инженерной проверки.

Нулевой ERC/DRC подтверждает проверенные правила KiCad и связность, но не
испытания автомобильных импульсов, тепловой режим, ток USB или подлинность
деталей. Первый заказ — инженерный прототип для стендовой квалификации,
не серийно аттестованный автомобильный модуль.
