# Проверки перед установкой

## Зрелость

- [x] Диагностика Микас на USB KKL: подтверждена в исходном проекте.
- [x] Распиновка 12-pin УАЗ и L9637D: сверена с Scanmatik и ST; на конкретной машине перепроверить мультиметром.
- [x] Официальный pinout Waveshare 2,1: известен.
- [x] Концепт интерфейса и корпуса: подготовлен; не испытан.
- [ ] Куплена конкретная ревизия платы дисплея.
- [ ] Прозвонен пучок, проверено питание, уровни логики и K-Line, выполнено схемное ревью.
- [ ] Проверена L9637D с имитатором на столе.
- [ ] Проверена ESP32-S3 и native USB при подключённой 4pin UART K-Line.
- [ ] Портирован протокол и тесты из старого проекта (время инициализации, эхо, ошибки).
- [ ] Сверены RPM, температура, напряжение, JQT, JAIR, INJ с OpenDiag.
- [ ] Подтверждена работа web-панели с телефона, пароль и QR реальной сети.
- [ ] Проверены пуски двигателя, длительные поездки, вибрация, солнечный свет, температурный режим и помехи.
- [ ] Проверена механическая посадка корпуса с выбранными контактами, креплениями и проводами.

## Порядок испытаний

A. Стенд: ограничение тока; 12→5 В; 5→3,3 уровни; короткий/обрыв питания; отказ безопасный; UART не тянет линию в ноль в неактивном состоянии.

B. Протокол: сначала чтение паспорта и одной величины, потом пул полей с частотами; raw trace и CRC/checksum (если используется) сравнить с Windows.

C. К автомобилю: двигатель заглушен, зажигание включено, только чтение; после проверки — запуск и работа на ХХ; сравнить со штатным USB KKL последовательно, не параллельно.

D. Полевые условия: восстановление после пропадания связи, отключения питания и ошибок; задержки интерфейса; Wi-Fi включен/выключен, шифрование и отсутствие управления автомобилем со смартфона.

## Критерии готовности к поездкам

Без аппаратных аварий и срывов работы ЭБУ, корректное выключение, не вводить водителя в заблуждение устаревшими показаниями; измеренные поля верны в допустимой погрешности; корпус не мешает управлению и штатным лампам.
