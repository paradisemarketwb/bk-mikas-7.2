# Референсы и независимость проекта

**Требование проекта:** программное обеспечение, электроника, корпуса, рисунки и компоновка платы разрабатываются самостоятельно. Чужие исходники и производственные файлы **не используются и не копируются**.

## Допустимые источники информации

- **Производители аппаратуры:** [ST L9637 datasheet](https://www.st.com/resource/en/datasheet/l9637.pdf), [Waveshare 2.1 hardware description](https://docs.waveshare.com/ESP32-S3-Touch-LCD-2.1). Используем фактические характеристики и pinout по технической документации.
- **Собственная прежняя диагностика Микас:** [uaz-mikas-diagnostics](https://github.com/paradisemarketwb/uaz-mikas-diagnostics). Рабочий Windows KKL/Микас служит основой для самостоятельного переноса прикладного протокола, без копирования приватных данных или логов в открытый репозиторий.
- **Сторонние проекты**, в том числе [erdemerciyas/K-line-Ecu](https://github.com/erdemerciyas/K-line-Ecu), могут быть изучены только концептуально для понимания реализуемости решения. **Никакие их драйверы, Gerber, UI, корпуса и программные модули не входят в BK-MIKAS.** Не считать эти проекты проверкой совместимости с ЭБУ Микас 7.2.

## Собственные разработки R1

- Таблица электрических цепей и изображения `assets/r1-*.svg`;
- параметрические корпуса `hardware/case/*-r1.scad`;
- структура экранов `ui/screens.json` и `tools/generate_layout.py`;
- собственные вычисления метрик `firmware/components/mikas_telemetry`.

Все файлы R1 записаны без личных данных. Запрещено добавлять в открытый GitHub VIN, персональные логи с геолокацией, реальные пароли Wi-Fi, секреты или данные владельца.
