# Проверенный собственный протокол Микас

Источник — `paradisemarketwb/uaz-mikas-diagnostics`, commit
`1e0ab5f22677e76904540b23176dce46d37a34b5`, файлы protocol.py,
mikas_profile.py и kkline_web.py. Чужая OBD-II реализация не используется.
Перенесены framing/escaping/checksum, read-only whitelist, corefieldmap и
таблица описаний ошибок. Приватные логи и идентификаторы владельца не копировались.

## Транспорт

9600 бод,8N1; старт — команда01 и ответ версии0B. Не выполнять ISO9141
fastinit или5baudinit без доказательств: в собственном профиле их не было.
Перед запросом выдерживается50мс, очищается вход; всё эхо сравнивается с TX.
Тело и дополнение суммы до нуля экранируются:0D→40CD,40→4000, затем терминатор0D.
Приём ограничен размером/таймаутом, проверяются checksum и точная длина поля.

Команда RPM `61 29` на проводе: `61 29 76 0D`. Команды записи62 и неизвестные
сервисные opcodes не проходят whitelist в transport. Разрешены01,02,51..58 и61PID.
Планировщик хранит сроки запросов и выбирает просроченное поле round-robin.
Периоды задают желательную частоту, не обещанную частоту под нагрузкой линии.
После3секунд без валидных полей связь сбрасывается и повторяется01.

| Метрика | PID | Преобразование |
|---|---|---|
|RPM|29|raw×40|
|ОЖ|1A|raw−40°C|
|Напряжение|1E|raw/10В|
|Дроссель|20|raw%|
|Воздух на впуске|1C|raw−40°C|
|УОЗ|26|signed8(raw)/2°|
|ДМРВ|21|UInt16LE; коэффициент не подтверждён|
|Топливо|40|UInt16LE/10л/ч, оценка ЭБУ|
|Впрыск|3F|UInt16LE/125мс|
|Лямбда1/2|4D/4E|raw, не вольты|

Состояния API:0недоступно,1валидно,2устарело,3нетЭБУ,4неподдерживается,
5недостаточно данных. Отсутствие ответа не доказывает неподдерживаемый PID:
такое поле остаётся без данных/устаревает, а не получает выдуманный ноль.

DTC читаются02 раз/10сек: count и пары code/flags. Проверяется длина и
зарезервированные биты flags. Повторяющиеся записи не создают новые события;
появление/исчезновение фиксируется в ограниченном журнале. Экран ошибок
считает данные актуальными не более15секунд.

Набор коэффициентов ещё надо сопоставить с конкретным ЭБУ и OpenDiag на машине.
Нет переноса функций управления форсунками, вентилятором, коррекциями и EEPROM.
Скорость/GPS/уровень топлива пока не предоставляются; л/100км и запас хода
без этих источников не вычисляются. Дополнительные37полей исходного проекта
остаются референсом для расширения, текущий ESP-профиль опрашивает11метрик.
