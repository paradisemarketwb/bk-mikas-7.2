# USB-KKL: проверка реализации

FTDI component2.1.1 / CDC component2.4.1 из официального Espressif registry,
ESP-IDF5.5.1, LVGL9.6.0. Цель VID0403/PID6001, интерфейс0,9600,8N1.
INF пользователя относится к FTDI CDM2.08.14 и содержит этот ID наряду с другими.
Модель реального чипа и работоспособность ESP32 с этим экземпляром кабеля
не определяются по INF.

Локальная ESP32-S3 USB Host сборка завершилась успешно; первая проверенная
сборка имела размер0x16c1e0байт в app-разделе3МиБ. Последующие исправления
проверяются матрицей safe/live/usb-kkl в GitHub Actions; авторитетен результат
для текущего commit. Локально registry-пакеты подключались через EXTRA_COMPONENT_DIRS;
при отключённом Component Manager CMake metadata FTDI дополнена только зависимостью
REQUIRES CDC, которую обычно задаёт manifest. Код драйвера не подменялся.

Host ASan/UBSan PASS: codec/формулы, JSON/история, потоковые фрагменты эха/ответа,
ошибки checksum/эха, отключение/timeout, запрет записи и RX ring wrap/overflow.
Chromium phone scenario и JS/SHA256 проверки PASS. Редактор экранов и renderer
не менялись; новый транспорт передаёт те же снимки телеметрии.

Исправлена документация по официальной схеме Waveshare original2.1:
два порта J2 CH343/J3 native, автоматический U10, J9 питание/USB/GPIO.
Производственные ZIP пересобраны после исправления руководств; электрические
схемы и PCB R2 не менялись, netlist/SHA и жгут проходят проверку.

Не проведены: enumeration с физическим KKL, USB hotplug/latency и токи,
взаимодействие радио/дисплея/USB под нагрузкой и обмен с реальным ЭБУ.
Протокол предусматривает повторное открытие; это не заявление о таких испытаниях.
