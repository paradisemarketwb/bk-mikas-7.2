## Использование результатов

[Симулятор](../simulator/README.md) можно собирать и использовать сейчас для
работы над UI. [20скриншотов](images/lvgl/) получены из реального LVGL framebuffer,
данные искусственные. [Прошивку](firmware/R2.md) можно собирать, но включать UART
следует после стендовой проверки схемы. K-Line и Wi-Fi по умолчанию выключены.

Для изготовления лабораторной PCB: передать папку
[hardware/kicad/r2/fabrication-prototype](../hardware/kicad/r2/fabrication-prototype/)
(медь/маски/шелкография/контур/сверловка). Для монтажа также нужны BOM и позиции.
Перед заказом согласовать via у площадки U2 и проверить footprints/разъёмы.
Это не законченный автомобильный прибор: не подключать прямые12В ко входу5В,
не использовать необработанное ACC как VS_PROT, не подключать native USB кGPIO19.

## Что остаётся разработать

Полный свободный редактор компоновки, import/export JSON и редактор с телефона,
OTA с проверкой образа, мини-графики/история/журналы, подробный экран DTC,
регулировка яркости, заставка с анимацией. Текущий интерфейс позволяет выбрать
первичный параметр пяти готовых приборов; это не полноценный редактор виджетов.
Имеющиеся C-декодеры не подменяют неподтверждённые источники скорости/пробега.

Изображение-референс десяти экранов отсутствует во вложениях текущего чата.
Текущий UI сделан по текстовым требованиям; визуальное соответствие не заявляется.

## Обязательные аппаратные проверки

1. Закончить защиту питания: предохранитель, reverse/load dump, cold crank,
   DC/DC с нагрузкой дисплея, внешний K-Line clamp и USB power isolation.
2. Осциллографом проверить GPIO19/43 и K-Line при reset/BOOT/ROM download,
   отключении питания, подключении USB-UART и brownout. JP1 разомкнуть для прошивки.
3. Подтвердить разъём/пины именно автомобиля и штатную диагностику при снятом БК.
4. Измерить геометрию Waveshare, проверить корпуса без давления на стекло.
5. Проверить RGB цвета/ориентацию/сенсор, PSRAM, tearing и Wi-Fi одновременно.
6. Сопоставить параметры с прежним KKL/OpenDiag, восстановление связи и нагрев.
