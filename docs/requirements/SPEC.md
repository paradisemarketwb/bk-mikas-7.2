# 1. ОБЩАЯ КОНЦЕПЦИЯ

Разрабатываем самостоятельный круглый сенсорный бортовой компьютер для автомобиля **УАЗ Хантер, двигатель ЗМЗ-409, ЭБУ Микас 7.2**.

Аппаратная основа:

- Дисплей **Waveshare ESP32-S3-Touch-LCD-2.1**.
- Диагональ 2,1 дюйма.
- Разрешение 480×480.
- Круглый IPS-экран.
- Сенсорное управление.
- ESP32-S3 на плате самого дисплея.
- RGB-контроллер ST7701.
- Контроллер сенсора CST820.
- Оперативная память PSRAM, встроенная Flash.
- Связь с ЭБУ посредством проводной K-Line.
- Интерфейс L9637D на собственной отдельной плате.
- Wi-Fi 2,4 ГГц для подключения телефона.
- Графическая библиотека **LVGL 9.6**, если совместимость выбранной версии ESP-IDF подтверждается сборкой. Зафиксировать конкретные версии зависимостей.

ESP32-S3 уже встроен в дисплей. Дополнительный микроконтроллер для K-Line не требуется, если нет технически доказанной необходимости.

**В автомобиле будет один круглый дисплей 2,1″.** Место установки и внешний кронштейн будут определены позднее. Сейчас нужен аккуратный самостоятельный корпус дисплея и корпус интерфейсной платы.

Главные принципы:

1. Устройство работает автономно, без интернета.
2. Показания ЭБУ приходят по проводу.
3. Wi-Fi нужен для настроек, телефона, обновлений и просмотра данных.
4. Интерфейс должен быстро запускаться и оставаться отзывчивым.
5. Все функциональные модули независимы.
6. Можно изменять и добавлять экраны без переписывания протокола ЭБУ.
7. Пользователь может самостоятельно настраивать комбинации приборов.

## 3.1. Интерфейс K-Line

Предусмотреть:

- L9637D;
- совместимость с логическими уровнями ESP32-S3;
- защиту UART;
- правильные состояния TX/RX при запуске и отключении;
- отключение передатчика от K-Line при необходимости;
- сервисную перемычку или иной надёжный способ отключения БК;
- защиту от типовых автомобильных помех;
- корректное поведение при пропадании питания;
- измерительные площадки для диагностики.

**Особое внимание GPIO0.**

В предыдущей ревизии R1B GPIO0 использовался для разрешения передачи через буфер. GPIO0 относится к загрузочным strapping-выводам ESP32-S3.

Проверь, допустимо ли такое решение вообще. Нельзя допускать неожиданной передачи в ЭБУ во время загрузки, прошивки, сброса, нажатия BOOT или отключения питания.

Если решение не обеспечивает безопасное состояние, **замени его аппаратно корректной схемой**, а не программной заплаткой.

Изучи доступные GPIO Waveshare и особенности переключения UART через USB-UART.

## 3.2. Подключение к УАЗ

Ориентир для штатной диагностической колодки УАЗ:

- Контакт 11 — K-Line.
- Контакт 12 — масса.
- Отдельное питание +12 В после включения зажигания.
- Постоянное питание с контакта 2 по умолчанию не используем.

Сверить разъём, его ориентацию и номера контактов по достоверной документации.

Физически предполагается аккуратная проводная врезка в автомобильную косу. Не нужно проектировать способ крепления к штатной колодке.

Схема должна показывать конкретно:

- Куда идёт каждый провод.
- Откуда берётся питание.
- Куда подключается масса.
- Как подключается K-Line.
- Куда подключаются UART TX/RX дисплея.
- Где расположены защитные элементы.
- Какие провода не подключаются.
- Где находится предохранитель.

Штатная линия диагностики должна сохранять работоспособность.

## 3.3. Питание

Разработать полноценную автомобильную цепь питания или подобрать конкретный защищённый модуль с подтверждёнными характеристиками.

Учесть:

- Напряжение бортовой сети 12 В.
- Повышенное напряжение при работающем генераторе.
- Просадки во время запуска двигателя.
- Переполюсовку.
- Импульсные помехи.
- Load dump.
- Предохранитель.
- Фильтрацию.
- Стабильные 5 В для дисплея.
- Отсутствие обратного питания через USB.
- Корректное выключение после отключения зажигания.

Не выбирать номиналы TVS, предохранителя, преобразователя и компонентов защиты наугад.

Если силовая защита лучше реализуется отдельным модулем, это допускается. Но в таком случае в проекте должна присутствовать конкретная схема его подключения и проверенные требования к нему.

## 6.1. Оптимизация под ESP32-S3

Экран 480×480 достаточно требователен к памяти и пропускной способности PSRAM.

Нужно не просто добиться вывода изображения, а подобрать разумную конфигурацию для постоянной работы.

Проверить и сравнить по документации и доступным тестам:

- RGB565.
- Частичные буферы и полные framebuffer.
- Один или два кадровых буфера.
- Bounce buffer.
- Размещение данных в PSRAM.
- Использование внутренней RAM.
- DMA и ограничения выравнивания.
- Работа Wi-Fi одновременно с графикой.
- Предотвращение tearing, сдвигов строк и зависаний.
- Обновление только изменившихся виджетов.
- Расход памяти на шрифты и изображения.
- Плавность анимаций.
- Скорость реакции на касание.

Не гоняться за максимальным FPS ценой стабильности.

Для автомобильного прибора приоритет:

**Стабильная работа → корректные показания → отзывчивость → плавная графика → декоративные эффекты.**

Интерфейс LVGL не должен блокировать обмен по K-Line.

Вызовы LVGL должны быть организованы потокобезопасно; диагностические задачи передают данные через отдельное хранилище телеметрии или очередь.

Создать документацию с выбранной конфигурацией буферов, оценкой памяти и объяснением решения.

## 7.3. Работа сенсора

Реализовать:

- Свайп влево/вправо между приборами.
- Переход в меню.
- Нажатие на показатель для его изменения.
- Возврат назад.
- Прокрутку списков.
