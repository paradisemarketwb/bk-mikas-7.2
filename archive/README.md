# История проекта

`r1b/` — исходные схемы R0/R1/R1B, старые инструкции, SVG и браузерное демо.
Эти материалы сохранены для истории, не используются действующей прошивкой,
генерацией PCB или CI. Для сборки использовать только корневой README и docs/.
Их старые относительные ссылки могут не соответствовать новой структуре.
