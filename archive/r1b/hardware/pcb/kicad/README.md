# KiCad R1B — история, не использовать для новой сборки

Файлы этого каталога сохранены для истории. R1B использует GPIO0 для активного LOW разрешения TX: нажатие BOOT может включить передачу, поэтому эта ревизия непригодна как окончательная автомобильная схема.

Актуальный проект: [BK-KLINE-R2](../../kicad/r2/README.md). Там находятся схема, настоящая двухслойная PCB, Gerber/Excellon, BOM и протоколы проверок. Автомобильное питание и испытания ещё блокируют эксплуатацию.
