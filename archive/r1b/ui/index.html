Документация проекта

Коснитесь дисплея или пролистайте влево/вправо. На телефоне работает без интернета.

Разделы макета

Автономная панель двигателя с сенсорным меню. В реальной версии данные поступают по проводу K-Line → L9637D → ESP32-S3, а телефон подключается отдельно по Wi-Fi.

QR-код содержит тестовую несуществующую сеть BK-MIKAS-DEMO с демопаролем. Настоящий QR будет динамическим на ESP32.

Концепт дизайна. Не реальная диагностика; HTML-файл не является прошивкой ESP32.
