Конструктор приборов

Выберите экран и добавьте виджеты. Положение задаётся в пикселях 480×480; видимая область круглая. Изменения применяются кнопкой «Сохранить».

Калибровки датчиков

Применяется Q = raw × K / делитель + B либо таблица. Коэффициенты задавайте по проверенным данным своего ЭБУ и датчика. kg/h = g/s × 3,6; mV = V × 1000.

Пропуски связи отмечаются разрывом графика. История показаний хранится в RAM; события ошибок сохраняются отдельно с ограничением объёма.

История ошибок

Обновление прошивки

Остановите двигатель. Нужен файл bk_mikas_r2.bin для ESP32-S3 из сборки этого проекта. Питание должно оставаться стабильным. Во время обновления обмен с ЭБУ отключается.

Заводской профиль

Сбрасывает только экраны. Калибровки сохраняются. Пароль Wi-Fi и ЭБУ не меняются.
