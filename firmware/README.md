# Прошивка ESP32-S3 · самостоятельная разработка

**На текущий момент firmware.bin нет.** Исходный рабочий обмен с Микас существовал в прежней программе для Windows/USB KKL. Он **не перенесён** на ESP32-S3. Текущая программа в этом репозитории состоит из независимых декодеров сырых значений, автотестов и генерируемых констант интерфейса.

## Своя архитектура (без переноса чужих драйверов)

- `kline_phy`: UART GPIO43/GPIO44 ↔ буфер U2 (TX) ↔ L9637D VCC=3,3 В; GPIO0 /OE высокий при загрузке, LOW только после готовности; инициализация, контроль эха и тайминги.
- `mikas_transport`: заголовки, checksum, запросы, ответы, timeout и проверка паспорта ЭБУ.
- `mikas_telemetry`: **уже присутствуют** C функции пересчёта некоторых сырых полей.
- `telemetry_store`: обновляемые снимки данных `value/unit/valid/time`.
- `ui_layout`: генерируемый реестр экранов, отдельный от протокола.
- `ui_lvgl`: собственная реализация рендеринга виджетов и жестов, заготовка не написана.
- `wifi`: будущий SoftAP/веб-API/QR и OTA.

**Официальная документация на чипы/дисплей** используется только как спецификация; чужой исходный код в проект не переносится.

## Можно проверить сейчас

В корне репозитория:

```sh
python3 tools/generate_layout.py
cc -std=c11 -Wall -Wextra -Werror -pedantic \
  -I firmware/components/mikas_telemetry/include \
  firmware/components/mikas_telemetry/mikas_telemetry.c \
  firmware/tests/test_telemetry.c -lm -o telemetry-test
./telemetry-test
```

`ui/screens.json` влияет только на описания экранов и генерируемый `firmware/components/ui_layout/generated/ui_layout_defaults.h`, без изменения вычислений. При редактировании макетов повторить генерацию.

## Следующие технические работы

1. Реализовать **свои** ESP-IDF драйверы ST7701S (RGB), сенсора, подсветки и UART по документации Waveshare/Espressif.
2. Проверить собственную плату L9637D на 3,3 В, а особенно **boot UART GPIO43**; на тестах JP1 оставлять разомкнутой до подтверждения безопасного состояния.
3. Перенести собственный проверенный пакет прикладного протокола Микас с Windows на C; пройти тесты с сохранёнными безопасными ответами имитатора, сравнить с OpenDiag.
4. Привязать renderer LVGL к метрикам `ui_layout` и дать выбор виджетов на самом приборе с сохранением в NVS.
5. Запустить Wi-Fi AP/связь с телефоном, динамический QR и OTA с откатом.
6. Зафиксировать конкретную ревизию Waveshare, собрать ESP-IDF binary, провести тесты и лишь затем публиковать готовую инструкцию прошивки.

Не считать наработки чужих K-Line / OBD-II систем совместимой прошивкой Микас 7.2 без собственной реализации протокола.
