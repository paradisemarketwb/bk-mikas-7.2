# Прошивка ESP32-S3 — подготовка и перенос

**Текущее состояние:** здесь есть протестируемый независимый C-компонент декодирования некоторых полей (`components/mikas_telemetry`), но **нет готового образа прошивки .bin для Waveshare**, нет полноценного K-Line стека и нет собранной прошивки с LVGL. Запускать только как проектную разработку, не выдавать демо за реальные данные.

## Рекомендуемый стек

- **ESP-IDF v5.3** для ESP32-S3 + PSRAM и штатного RGB дисплея; LVGL 8.2 как в проверенном стороннем примере.
- Аппаратная поддержка Waveshare ST7701S / CST820: использовать **официальные примеры** производителя или разбирать [MIT-проект с тем же экраном](https://github.com/erdemerciyas/K-line-Ecu) (см. [REFERENCES](../docs/REFERENCES.md)).
- UART K-Line: ESP32 GPIO43 TX / GPIO44 RX, внешний L9637D и согласование, см. [WIRING](../docs/WIRING.md). Плата UI и транспорт — разные модули.

## Компонент с формулами

`components/mikas_telemetry/include/mikas_telemetry.h` + `mikas_telemetry.c`: без ESP-IDF-зависимостей, не выполняет никаких запросов, только переводит достоверно считанные сырые байты в физические величины. Следующий этап — взять реальные кадры Микас из исходного профиля, проверить границы и дописать транспорт и планировщик.

На ПК с компилятором C: `cc -std=c11 -Wall -Wextra -pedantic -I firmware/components/mikas_telemetry/include firmware/components/mikas_telemetry/mikas_telemetry.c firmware/tests/test_telemetry.c -lm -o /tmp/bk-mikas-test && /tmp/bk-mikas-test`.

## Последовательность создания реальной прошивки

1. Проверить демо Waveshare с touch и яркостью без подключения автомобиля.
2. Подключить физический UART + L9637D и стендовые тесты, соблюдая 5/3,3 В.
3. Взять из старой Windows-диагностики точную инициализацию Микас, ответы, эхо/контрольные суммы, перенос в C.
4. Связать K-Line poller → буфер `TelemetrySample(valid,age_ms,...)` → UI LVGL; отображать «—» для отсутствующих данных.
5. Добавить SoftAP только с уникальными учётными данными, локальный web-dashboard и QR текущей сети. Включение AP не должно останавливать опрос ЭБУ.
6. Собрать и прошить реальный ESP32-S3, прогнать тесты и сохранить версии инструментов, бинарники, инструкции восстановления.

**Не прошивать напрямую чужую KWP2000 прошивку как «готовую для Микас»: это разные прикладные протоколы.**

## Питание/USB

Две USB-C розетки на плате: USB-UART отключает GPIO43/44 от 4pin разъёма; для отладки, когда используется UART к ЭБУ, выбирать native USB (точное назначение сверить с маркировкой Waveshare). Бортовое питание и питание USB одновременно без развязки не соединять.
