# BK-POWER-R2 — незавершённая контрольная точка

Схема/PCB/BOM сохранены при паузе по запросу пользователя.
Трассировка и итоговые ERC/DRC/экспорты не завершены. Не использовать для заказа
или подключения без завершения проверки. [Точка продолжения](../../../docs/PAUSE_CHECKPOINT.md).

Тракт: ACC через внешнийinline2A → LM74800/common-sourceMOSFET/TVS →
VS_PROT → RECOMR-78B5.0-2.0 → LM66100ORing с отдельным входомUSBVBUS →5V_OUT.
Конкретные номиналы и footprint сохранены в KiCad и BOM; окончательные расчёты
и электрическая квалификация не завершены. LM66100 ограничивает ток независимо
от номинального2A преобразователя; USB-хост также имеет собственный токовый бюджет.

Разъёмы: J1.1 ACC_RAW/J1.2GND; J2.1VS_PROT/J2.2GND/J2.3 5V_OUT/J2.4GND;
J3.1 USB_HOST_VBUS/J3.2GND. Подробный жгут описан в docs/WIRING.md.
