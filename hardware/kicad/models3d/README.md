# Используемые модели KiCad

Только модели деталей двух плат BK-R2. Источник и SHA256 каждого STEP: [SOURCES.json](SOURCES.json). Авторство сохранено в заголовках исходных моделей.

Лицензия коллекции: [CC-BY-SA4.0 с исключением для электронных проектов](LICENSE.md). Эти модели визуализируют соответствующие стандартные корпуса; они не подтверждают точные допуски конкретной партии деталей.

Экспортёр проекта использует этот каталог как KICAD9_3DMODEL_DIR. При ручной работе установите тот же параметр в KiCad Preferences→Configure Paths либо используйте установленную библиотеку KiCad. STEP плат в exports уже включает доступные модели и не зависит от временных файлов.
