## UART и аппаратная блокировка

J2 — собственный JST-XH 6 pin, **не порядок контактов Waveshare**:

| J2 | Цепь | Waveshare |
|---|---|---|
|1|5V|VBUS после внешней защиты/развязки USB|
|2|GND|GND|
|3|3V3|выход 3V3 дисплея|
|4|ESP_TX|GPIO43 / TXD|
|5|ESP_RX|GPIO44 / RXD|
|6|TX_ARM|GPIO19 / D−, USB отключён|

GPIO0 не подключается. R4 100k удерживает затвор Q1 (2N7002) низким; R3 10k держит `/OE` U2 высоким. Только HIGH на GPIO19 открывает Q1 и разрешает буфер. R6 10k удерживает TX L9637D высоким при отключённом буфере. GPIO19 переиспользует USB D−: **native USB запрещён**, USB к этим линиям не подключать. Для прошивки использовать UART0 с физическим размыканием JP1. На дисплее проверить фактическую конфигурацию USB-UART переключателей. Консоль UART0 прошивки отключается; диагностический UART можно маршрутизировать UART1 на43/44.

JP1 разрывает только нашу ветвь K-Line; штатный диагностический провод автомобиля не перерезается. Снимать JP1 перед прошивкой и стендовым исследованием сброса/BOOT. Безопасность стартового состояния подтверждать осциллографом, включая ROM и brownout; предположение о GPIO19 в ROM требует проверки реальной ревизии Waveshare.

## Питание и оставшиеся блокеры

J1.1 — **VS_PROT**, защищённое +12V после зажигания, J1.2 — GND, J1.3 — ответвление K-Line. J3.1 — внешние стабилизированные 5V, J3.2 — GND. J1.1 нельзя выдавать за вход готовой защиты автомобиля. Постоянный +12V колодки не подключается. Контакты автомобильной колодки11/12 остаются ориентиром, распиновку именно автомобиля подтвердить перед монтажом.

В R2 нет собственного законченного automotive power frontend. До допуска нужны:

1. Выбранные предохранитель у источника ACC, защита от переполюсовки и load dump, фильтр и DC/DC 5V с подтверждённым током дисплея. L9637D: VS4.5–36V, 40V только transient, VCC3–7V; 3.3V допустимо по datasheet Rev8, table5.
2. Внешний ограничитель помех K-Line с проверкой диапазона выводов L9637D. В текущей схеме есть встроенные защиты трансивера, **внешнего TVS K-Line нет**.
3. Развязка VBUS и автомобильных5V, исключающая USB backfeed; фактическая схема Waveshare должна быть сверена. До её завершения не питать дисплей от двух источников одновременно.
4. Нагрузочное испытание5V, осциллограммы пуска/остановки/BOOT/прошивки и связи; проверка проводов и условий нагрева.

Конкретный технический вариант для следующего силового прохода — [TI LM74800-Q1](https://www.ti.com/lit/ds/symlink/lm7480-q1.pdf), common-source topology, раздел10.3 (unsuppressed load dump). Это **контроллер для разработки защиты, не выбранный готовый модуль**. Требуются рассчитанные MOSFET, TVS, OV threshold и преобразователь; случайный buck12→5V не закрывает эти требования.

При заказе лабораторного прототипа: FR-4,1.6мм,2 слоя,35мкм Cu, зазор0.25мм, минимальное сверление0.25мм, via0.5/0.6мм; согласовать возможности изготовителя. В переходе земли U2 есть via в/у площадки: для автоматического монтажа требуется согласовать заполнение/маску с фабрикой, иначе возможен уход припоя. Проверить ориентацию разъёмов, отверстия и модель компонентов до заказа.

## Проверка

`kicad-cli sch erc BK-KLINE-R2.kicad_sch -o reports/ERC.txt`

`kicad-cli pcb drc BK-KLINE-R2.kicad_pcb -o reports/DRC.txt`

`kicad-cli sch export netlist --format kicadxml -o reports/netlist.xml BK-KLINE-R2.kicad_sch`

Из корня: `/usr/bin/python3 tools/check_r2_hardware.py`. Сравнивает45 подключённых площадок с экспортированной схемой и проверяет структуру7 Gerber+Excellon. Эти проверки не заменяют стенд/EMC. SHA256 исходников и производственных экспортов сохранены в `reports/SHA256.json`.

Источники: [ST L9637D](https://www.st.com/resource/en/datasheet/l9637.pdf), [TI SN74LVC1G125-Q1](https://www.ti.com/product/SN74LVC1G125-Q1), [Waveshare](https://docs.waveshare.com/ESP32-S3-Touch-LCD-2.1). Испытаний на физическом устройстве не было.
