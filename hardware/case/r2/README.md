# Корпуса R2 — модели для проверки посадки

- `adapter-r2.scad`: основание/крышка/разнесённый вид. PCB65×52мм, отверстия(3,24),(62,3),(3,49),(62,49)мм точно следуют R2 PCB. Стойки5мм, пилотные отверстия2мм под выбранный крепёжM2.5, кабельные окна и мостики под стяжки.
- `gauge-r2.scad`: перенесённая параметрическая концепция круглого корпуса, задней крышки и прокладки. **Габариты75/85мм являются допущениями R1, а не измерением Waveshare.** Окончательная посадка дисплея и фиксация без давления на стекло не закрыты.
- `stl/`: пять отдельных экспортов OpenSCAD. Успешный CSG/STL экспорт не подтверждает посадку или механическую прочность.

Материал: PETG для примерки, ASA при подтверждённом температурном режиме и технологии печати; слой0.2мм, стенка2.4мм. Сначала измерить дисплей, разъёмы, высоту деталей и изгиб кабелей. Для платы проверить ориентацию выводов и выступы Phoenix/JST. Крышка адаптера фрикционная; до автомобильного монтажа нужно проверить удержание при вибрации и при необходимости добавить винтовой крепёж.

Экспорт: `openscad -o adapter-base.stl -D 'part="base"' adapter-r2.scad`; для крышки `part="lid"`. Дисплей: `part="body"`, `"rear"`, `"spacer"`. Визуальный разнесённый вид адаптера `part="exploded"`.

Проверено `python3 tools/check_case_mesh.py`: все пять STL содержат одну замкнутую оболочку без открытых/немногообразных рёбер. Отчёт: `hardware/kicad/r2/reports/case-mesh.txt`. Проверка не доказывает посадку.
