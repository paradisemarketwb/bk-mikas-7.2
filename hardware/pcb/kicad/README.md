# KiCad: электрическая схема BK-KLINE-R1B

**Стадия:** настоящая редактируемая KiCad-схема `bk-kline-r1b.kicad_sch` и собственная библиотека `BK_MIKAS.kicad_sym` (не только SVG). Всё построено с нуля по документации ST, TI и Waveshare. **Плата (.kicad_pcb), производственные Gerber, подтверждённое питание автомобиля и испытания пока отсутствуют.**

## Файлы

- [bk-kline-r1b.kicad_sch](bk-kline-r1b.kicad_sch) — **открыть в KiCad 8/9/10**, A3, схема с реальными экземплярами компонентов и именованными электрическими сетями.
- [BK_MIKAS.kicad_sym](BK_MIKAS.kicad_sym) — наша локальная библиотека символов с номерами ног, типами выводов и footprint placeholders.
- [sym-lib-table](sym-lib-table) — привязка библиотеки к папке проекта; файлы должны находиться вместе.
- [ERС GitHub Actions](https://github.com/paradisemarketwb/bk-mikas-7.2/actions/workflows/kicad-schematic.yml) — KiCad CLI запускает проверку, экспортирует PDF/SVG, netlist; результаты во вкладке **Artifacts** конкретного запуска.
- [Сборочная инструкция](../../../docs/GETTING_STARTED.md) · [Подробное назначение выводов](../../../docs/WIRING.md).

## Подготовка KiCad в Windows

1. Установить KiCad 9 или 10 с официального сайта.
2. Скачать ZIP всего репозитория с GitHub или сделать `git clone`.
3. Открыть `hardware/pcb/kicad/bk-kline-r1b.kicad_sch` через Schematic Editor.
4. В `Tools → Electrical Rules Checker` запустить ERC (результаты с датой см. workflow). Для изменения платы используйте именно KiCad, а не картинки SVG.
5. В `File → Plot` экспортировать схему PDF, либо скачайте автоматические файлы из GitHub Actions.
6. Номиналы, посадочные места и разъёмы проверить перед разводкой. **Стандартные вертикальные PinHeader у J1/J2/J3 используются как временные footprint-заглушки, это НЕ подходящие автомобильные разъёмы.**

## Зафиксированные соединения

| Сеть | Контакты |
|---|---|
| ACC_PROT | J1.1, U1.7, C2.1 |
| GND | J1.2, J2.2, J3.2, U1.5, U2.3, C1.2, C2.2, C3.2 |
| K_LINE_IN | J1.3, JP1.1 |
| K_TO_CHIP | JP1.2, U1.6 |
| 5V | J3.1, J2.1 |
| 3V3 | J2.3, U1.3, U2.5, R3.1, C1.1, C3.1 |
| ESP_TX | J2.4, R1.1 |
| U2_INPUT | R1.2, U2.2 |
| TX_GATE_ENABLE | J2.6 (GPIO0), U2.1, R3.2 |
| U1_TX | U2.4, U1.4 |
| U1_RX | U1.1, R2.1 |
| ESP_RX | R2.2, J2.5 |

Обозначения U1: **ST L9637D**, U2: **TI SN74LVC1G125-Q1**. U1 выводы 2 (LO) и 8 (LI) оставлены NC. J2 — **наш** 6-контактный промежуточный разъём, от которого шесть жил идут на *конкретные позиции* 12PIN Waveshare, см. WIRING. На JP1 нельзя «закоротить оба конца» в netlist постоянно — перемычка физически разрывает ветвь.

## Важно до изготовления PCB

- Уточнить реальный автомобильный блок питания/защиту 12→5 В (эта схема начинается **после** защитного входа ACC_PROT); в KiCad нет ошибочно выбранного TVS без расчёта выбросов.
- Проверить схемный ERC, а затем всю электрическую часть на столе, включая VCC=3,3 В и boot UART0 GPIO43.
- GPIO0 на BOOT способен разрешить передачу через U2; перед прошивкой/BOOT аппаратно разомкнуть JP1.
- Прежде чем делать 2-слойную плату и файлы производства, выбрать разъёмы с фиксацией, измерить фактический 12PIN кабель Waveshare, определить условия размещения платы и массы.
- **Пока нельзя утверждать, что схема автомобильных испытаний пройдена.**

Технические источники: [ST L9637 datasheet](https://www.st.com/resource/en/datasheet/l9637.pdf), [TI SN74LVC1G125-Q1](https://www.ti.com/product/SN74LVC1G125-Q1), [Waveshare 12PIN](https://docs.waveshare.com/ESP32-S3-Touch-LCD-2.1).
