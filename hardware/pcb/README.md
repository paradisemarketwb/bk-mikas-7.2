# Проект собственной PCB BK-KLINE-R1B — netlist и компоновка

**R1 prototype / design review required.** Схема [r1-electrical.svg](../../assets/r1-electrical.svg) и [docs/WIRING.md](../../docs/WIRING.md) написаны независимо на основании ST. Изготовленные платы и проверенные Gerber пока отсутствуют.

## Спецификация для перевода в KiCad

- Тип: двусторонняя FR-4, 1,6 мм, 35 мкм; **ориентировочный** габарит 36×26 мм (корректировать после подбора разъёмов), без платы DC/DC.
- U1 L9637D SO-8 / SOIC-8, pin1 маркер на шелкографии. Footprint из библиотек KiCad со сверкой ширины корпуса 3,9 мм и шага выводов 1,27 мм.
- U2 SN74LVC1G125-Q1, SOT-23-5: pin1 /OE ← GPIO0 через J2-6 с R3 10кОм к 3V3; pin2 A ← GPIO43 через R1 1кОм; pin3 GND; pin4 Y → U1 pin4 TX; pin5 VCC 3V3 + C3 100нФ. R2 1кОм между U1 RX pin1 и GPIO44. C1 100нФ для U1 VCC, C2 100нФ для U1 VS.
- J1 автомобильный 3pin ACC_PROT / GND / K; J2 6pin к разветвлённому 12PIN хвосту Waveshare; J3 2pin 5V/GND от защищённого DC/DC.
- JP1 2pin перемычка K-Line (разрывает **только** диагностическую ветвь БК).
- Не предусматривать дополнительную низкоомную подтяжку K-Line к +12 В до проверки существующей автомобильной линии.
- Подписать названия цепей в шелкографии: 12V, GND, K, 5V, 3V3, TX, RX. Test pads около платы.
- Не вести автомобильную линию K параллельно линиям сенсора, антенне Wi-Fi или RGB дисплею. Общий GND, аккуратная защитная разводка у входа, миниатюрный корпус с фиксатором кабеля.
- В перечне цепей [NETLIST.csv](NETLIST.csv) приведены все электрические связи R1. Это **не** Gerber, и пока не импортируемый KiCad netlist.

## Процесс получения производственных файлов

1. Создать проект KiCad из этой схемы/netlist и выбрать конкретные физические разъёмы.
2. Проверить правильность ориентации SO-8, размещение C1/C2 и пути тока VS/GND.
3. Запустить ERC (Electrical Rules Checker), DRC (Design Rules Checker), визуальную 3D-проверку.
4. Проверить физическую нумерацию 12-pin жгута, проверить подключение питания при снятом дисплее.
5. Изготовить **одну** плату и протестировать на лабораторном БП/имитаторе прежде, чем заказывать тираж.
6. Только после стендового прогона добавить Gerber, сверловку, BOM/CPL и акт проверки.

**R1B содержит аппаратный запрет TX:** буфер U2 высокоомный при GPIO0 HIGH; только прошивка после запуска K-Line-стека переводит GPIO0 в LOW. GPIO0 — strapping pin, внешняя подтяжка 10к к 3V3. При кнопке BOOT GPIO0 может оказаться LOW, поэтому на обслуживании JP1 размыкать. Требуется стендовый осциллографический тест.
