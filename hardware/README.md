# BK-KLINE-R1B — полностью собственный интерфейс Микас 7.2 ↔ ESP32-S3

**Электрическая схема создана самостоятельно по даташиту L9637D**. Сторонние Gerber не используются и не копируются. Реальный заказ PCB не разрешён до схемного ревью и DRC. Здесь есть таблица цепей и вид схемы, но **нет пока проверенного KiCad-проекта/Gerber**.

## Принятый вариант

L9637D **VCC = 3,3 В** от дисплея, **VS = защищённое 12 В после зажигания**, RX через R2 1 кОм к GPIO44; TX через R1 1 кОм и буфер **U2 SN74LVC1G125-Q1** на GPIO43. U2 /OE ← GPIO0 с R3 10 кОм к 3V3; по умолчанию передача запрещена. C1/C2/C3 по 100нФ. Нет внешнего 5-вольтового согласователя. Стендом проверить пороги логики и отсутствие нежелательных посылок boot-ROM на UART0 TX. Для прерывания только **нашей ветви K-Line** — сервисная перемычка JP1.

Автомобильный вход защиты + DC/DC не интегрирован на микроплату в R1: это **отдельный модуль с документированной защитой**, перед окончательным монтажом подобрать конкретную модель, её номиналы и клеммы. Дизайн корпуса и размещение USB требуют примерки к реальной плате Waveshare, до этого размеры только предварительные.
