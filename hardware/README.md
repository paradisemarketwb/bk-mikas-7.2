# Аппаратная часть BK-R2

- [BK-KLINE-R2](kicad/r2/README.md): схема и разведённаяPCB65×52mm, аппаратная блокировкаTXGPIO19, L9637D,22Ω/SMAJ18A защита K-Line.
- [BK-POWER-R2](kicad/power-r2/README.md): схема/PCB90×70mm, LM74800 common-source input protection, конкретный RECOM5V, два идеальных диода USB/авто и общий TPS2553 current limiter. [Расчёты и границы](kicad/power-r2/CALCULATIONS.md).
- [Корпуса](case/r2/README.md): геометрия дисплея по официальномуWaveshareCAD, комбинированный корпус двухPCB,7STL и реальныеCAD-рендеры.

ERC/DRC и эквивалентность схемного netlist проверены для обеихPCB, производственные экспорты получены из настоящихKiCad плат. Это инженерный комплект для изготовления/стенда, **физические испытания на автомобиле не выполнены**. Условие допуска описано в расчётах и инструкциях сборки; нулевойDRC не является сертификатом импульсной стойкости.

R0/R1/R1B находятся в [архиве](../archive/r1b/hardware/). Не использовать их GPIO0-схему и старые размеры корпуса как действующую ревизию.
