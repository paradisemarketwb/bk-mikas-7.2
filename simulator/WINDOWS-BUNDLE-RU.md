# Windows x64: запуск Hunter preview

Распакуйте весь ZIP в обычную доступную для записи папку. Не запускайте .exe
прямо внутри архива. Рядом с bk_sim.exe должна оставаться SDL2.dll.

- Reference.cmd — Hunter Reference; Classic.cmd — Classic R2.
- Каждый ярлык сохраняет свой hunter-*-profile.json. Повторный запуск возвращает
  компоновку, стиль и коэффициенты. Удаление файла сбрасывает этот вариант.
- ↑/↓ или вертикальный свайп мышью — приборы; ←/→ — метрики того же прибора.
- Меню → Настройки → редактор; E — перетаскивание, Enter — сохранить.
- Ctrl+S — сохранить, Escape/крестик — выйти с сохранением. F12 — PPM-снимок.
- +/− обороты, W/S температура, V напряжение, D ошибки, C связь, G внешний источник.
- M/L — включить примерную калибровку MAF/лямбды; J/K — коэффициент MAF.
- 1/2 загружают заводские наборы; свои изменения перед этим сохраните отдельно.

Все значения этого .exe — СИМУЛЯЦИЯ. В реальной машине нет GPS/уровня топлива
без подключённого проверенного источника. Примерные коэффициенты из profiles
предназначены для проверки симулятора, не являются подтверждёнными формулами ЭБУ.
`bk_sim.exe --reference --demo` показывает пример с калиброванными значениями.
Для своей конфигурации используйте `--import my.json --export my.json`.

Проверка повторного запуска: настроить Classic, Ctrl+S, закрыть, открыть
Classic.cmd — сравнить координаты. Затем повторить с Reference.cmd.
Дополнительно применить свой коэффициент MAF, сохранить и сверить после открытия.

Сборка: Visual Studio 2026 x64, SDL2 via vcpkg, LVGL9.6.0, cJSON1.7.19.
CI запускает .exe на Windows Server2025; ручная проверка мыши/окна на Windows10
остаётся проверкой пользователя. На машине без Visual Studio при ошибке
VCRUNTIME140.dll установите Microsoft Visual C++ Redistributable x64.
Лицензии библиотек/шрифтов включены в папку licenses.
